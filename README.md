# Thesis
This repository contains the Jupyter Python code used for data preparation and econometric analysis in this study. 

The file build_dataset_.ipynb includes the code used to transform the original Excel file (new_dataset_brend_normalized_finalv13) into a panel dataset.

The file analysis_2018_2013.ipynb contains the Jupyter Python code used for the empirical analysis of the 2013 and 2018 policies. In particular, it includes the code for estimating the Difference-in-Differences models and event-study specifications applied in the study.
