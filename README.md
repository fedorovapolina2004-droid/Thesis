# Thesis

Hello everyone,

I am a fourth-year student in the KHU–HSE Double Degree Programme "Economics and Politics in Asia". This repository contains the Jupyter Python code used for my thesis titled **“The Impact of Indonesian Government Industrial Policies on the Domestic Market and Automotive Trade in 2010–2025.”**

The repository includes several files that reflect the main stages of the work. The file **build_dataset_.ipynb** contains the code used for data preparation. In particular, it transforms the original Excel file, **new_dataset_brend_normalized_finalv13**, into a panel dataset suitable for econometric analysis.

The files **filtration 2013 (2011–2015).ipynb** and **filtration 2018 (2016–2020).ipynb** represent an intermediate step in the research process. These notebooks are used to filter the relevant vehicle models from the larger dataset for the 2013 and 2018 policy analyses. This step was necessary before applying the event-study and Difference-in-Differences models, as each policy required a specific analytical sample and time window.

The file **analysis_2018_2013.ipynb** contains the code used for the analysis of the 2013 and 2018 policies. Specifically, it includes the estimation of Difference-in-Differences models and event-study specifications applied in the study.

Please note that all code is written for **Jupyter Python**. If you notice any inconsistencies, errors, or areas that could be improved, comments and constructive criticism are very welcome.
